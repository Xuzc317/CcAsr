DESIGN REVIEW

01 · 现状评审：六个维度的诊断

基于对 app/src 全部 5 个页面组件、全局样式与 14 张现状截图的走查。总体判断：功能与信息架构成熟，视觉层处于「能用但不成体系」的阶段 —— 深色顶栏 + 浅色正文两套语言并存、颜色大量硬编码、品牌标识双轨并行。

维度现状问题改进建议（2.0 方案）
配色 高双主题割裂：CSS 变量定义了一套暗色主题（#1a1a2e / #16213e / #e94560），但正文区域是白色 —— 顶栏深蓝、正文白、品牌红，三色互相无过渡。
高状态色不统一：完成=#2a9d8f（青绿）、处理中=#4361ee（蓝）、失败=#e94560（红）、品牌=#e94560（红）—— 红既是品牌色又是错误色，语义冲突。
中组件内硬编码 40+ 处颜色（#eee / #ddd / #f2f2f7 / #c0392b…），与变量体系完全脱节，无法整体换肤。 		统一为浅色「纸面」单主题：暖白底 + 石墨墨 + 靛紫品牌色（错误红与品牌色彻底分离，改用 #D92D20）。全部颜色收敛为 Design Tokens（第 03 节），组件禁止内联色值。
布局 中页面内容贴边感强：列表页无最大宽度约束，宽屏下内容横向拉扯、行宽失控。
中会议详情页信息层级挤：标题、统计、操作按钮、播放器、工具条层层堆叠，缺少分区与留白节奏。
中录音队列 Tab 条目过「瘦」，一屏大量空白，失败原因等信息密度低。 		内容容器统一 max-width 1120px 居中；详情页采用「页头 → 分段控件 → 播放器 → 工具条 → 内容」的固定节奏，每区间隔 16–24px；队列行增高至 52px 并补充时长/时间戳列。
字体 高无字体层级体系：字号出现 20 / 14.5 / 13 / 12.5 / 12 / 11.5 / 10.5 等 10+ 种零碎值。
中时间戳等数字未用等宽字体，列对齐依赖侥幸；字重只有 400/500/700 三档混用。
中标题无字距与行高规范。 		收敛为 6 级字阶（28/20/16/14/13/12），正文 14px、辅助 12–13px；时间戳/时长统一等宽数字（font-variant-numeric: tabular-nums）；标题 -0.01em 字距。
间距 中间距不成体系：padding 出现 13px 16px、12px 16px、6px 0 10px 等任意组合，无 4px 基准网格意识。
中圆角 6 / 8 / 10 / 12 混用；卡片内部边距不一致。 		采用 4px 基准间距标尺（4/8/12/16/24/32/48/64），圆角收敛为 6/10/14/20 四档，卡片统一 16–20px 内边距。
一致性 高按钮至少 4 种样式来源（.btn 类 + 组件内联 + 原生 audio 控件 + 链接式），悬停态有的有、有的没有。
中说话人标签在不同页面形态不同（蓝底胶囊 / 绿底胶囊 / 纯文字）。
中状态徽标颜色与文字组合各页面自造。
优值得保留：纪要的多色分栏卡片、证据徽章交互、底部确认栏逻辑——这些差异化组件是有信息价值的。 		沉淀 统一组件库（第 04 节）：按钮 3 变体 × 3 尺寸、说话人标签用有序调色板（说话人身份跨页面恒定同色）、状态徽标 5 态全组件复用。
品牌 高双标识并行：顶栏是纯文字红字 “CcAsr”，favicon 却是蓝紫渐变声波方块 —— 两个品牌互相不认识。
中Logo 缺乏辨识度：通用声波渐变方块与大量音频/AI 应用雷同；无品牌图形语言延伸到 UI。 		重新设计 Logo（第 06 节）：「声波 → 文字行」概念，统一顶栏、favicon、空状态插画、加载动画的品牌语言。

可优化 / 可移除项（不改变功能的前提下）

  • 顶栏精简：现状深蓝色顶栏只放了一个文字 Logo 和副标题，信息价值低 → 改为浅色细顶栏（Logo + 产品名），把视觉重心还给内容。
  • 「已保存」常驻按钮：转录页右上角的「已保存」是一个不可点的状态展示 → 改为工具条上的文字状态指示（“所有更改已保存” / “待保存 N 处”），需要确认时再出现主按钮，减少常驻按钮噪音。
  • 原生 audio 播放器：浏览器默认控件与整体风格脱节 → 定制迷你播放器（第 05 节有设计稿），保留全部播放能力。
  • 录音 Tab 空态：现状只有一行灰色小字 → 增加引导空状态（图标 + 说明 + 操作入口）。
DESIGN DIRECTION

02 · 设计方向：「纸面工作台」

CcAsr 的本质是把声音变成一份可靠的文档。新设计语言呼应这个本质：像一张干净的纸，让转录文本与纪要成为绝对主角；品牌靛紫只出现在「需要行动」的地方——按钮、当前态、证据、说话人。

✓
纸感留白暖白纸面背景（#FAFAF7），内容卡片纯白浮起，用留白而非分割线划分区域。
✓
克制的色彩全页面 90% 为黑白灰 + 品牌靛紫；语义色只用于状态，说话人色只用于身份识别。
✓
清晰的字体层级六级字阶 + 等宽数字，转录时间轴列严格对齐。
✓
一致的组件语言所有交互组件共享同一套圆角、阴影、动效曲线（150ms ease）。

BRAND IDENTITY

06 · Logo 设计稿

概念：「声波，落成文字」。左侧高低起伏的声波竖条渐次收束、过渡为右侧三行文字横线——一眼说清 CcAsr 做的事（语音 → 文本），也与产品核心的「时间轴 + 文本」界面语言同构。

主稿 · 靛紫渐变（应用图标 / favicon）
横排组合 · 顶栏 / 文档页眉
深底适配（深色截图 / 分享卡片）

设计说明

  • 图形：7 根圆头线条，振幅从左至右递减并旋转 90° 成为文字行——「转录」的动作被画进 Logo 里；负形节奏与转录页面的「时间戳 + 文本行」版式一致。
  • 配色：135° 靛蓝（#4F46E5）→ 紫（#8B5CF6）渐变，与 UI 品牌色同源；单色稿可用纯 #4F46E5，保证 16px 以下小尺寸清晰。
  • 与旧版差异：旧 favicon 是「渐变方块 + 纯声波」，与同类音频产品雷同且未进入界面；新版把声波「变成文字」，辨识度来自概念而非装饰，并统一了顶栏文字标与图标两个分裂的品牌。
  • 延伸：加载/转录中的动画可直接让 7 根线条按振幅依次起伏（约 1.2s 循环），品牌语言贯穿到每个等待瞬间。
HANDOFF

07 · 落地清单

实施顺序建议
  • P0 主题切换：以第 03 节 Tokens 重写 global.css，删除暗色变量组；正文区改为纸面底色。
  • P0 颜色清剿：5 个组件内约 40 处硬编码色值全部替换为变量（可全局搜索 #[0-9a-f] 逐一收敛）。
  • P1 组件统一：按钮 / 徽标 / 说话人标签 / 证据徽章抽成共享组件，说话人色走调色板函数。
  • P1 顶栏 + Logo 替换：新 logo.svg / favicon.svg 已随本方案提供，直接替换 public/ 下文件。
  • P2 播放器定制：封装 AudioBar 组件，保持现有共享 audio 逻辑不变，仅换肤。
  • P2 空状态与加载：录音队列空态、纪要生成中的 Logo 声波动画。
