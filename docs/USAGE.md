# 使用指南

[项目首页](../README.md) · [安装指南](../INSTALL.md) · [API 参考](API.md)

## 导入录音

在「我的会议」新建会议，进入后拖入录音或一次选择多个文件。

- 支持 wav、mp3、m4a、flac、ogg、aac、wma、mp4，单文件上限 500 MB。
- 文件按文件名排序，建议用 `01-开场.m4a`、`02-讨论.m4a` 表示实际顺序。
- 网页可选中、粤、英、日、韩或自动检测；自动检测仍走 SenseVoice 的覆盖范围。
- 上传后自动串行转录，在「录音」页查看状态和重试失败项。
- 队列运行时不能追加；完成后可继续添加。新增录音会重新合并，建议录音全部处理完再集中校对。

## 阅读纪要与回听

全部录音处理完后，系统统一说话人、合并时间轴，并在已配置 LLM 时尝试生成纪要。

纪要包含议题、表格、时间轴与待办等版式。章节旁的 `▶ 02:33` 表示可定位的转录出处，点击切换到合并转录并回放原声。

并非每个章节都有时间戳：后端只保留能匹配转录片段的引用，此校验不等于摘要语义验证。

可上传议程或参会名单等文本材料（推荐 UTF-8 的 .md、.txt），再重新生成纪要。当前接口不解析 PDF 或 Word。

## 校对与保存

| 操作 | 入口 |
| :--- | :--- |
| 改文字 | 双击句子正文 |
| 改说话人显示名 | 顶部说话人工具条 |
| 调整单句归属 | 点击句首说话人标签 |
| 批量调整归属 | 工具栏「批量改判」 |
| 播放上下文 | 点击转录片段 |

修改先保存在草稿，切换会议内标签页会保留。底部栏汇总变化，点「确认修改」写回后端；「撤销全部修改」回到上次保存状态。批量改判也先进入草稿，可撤销本次操作。

其他页面已保存更新时，后端拒绝旧修订覆盖，需要刷新后再编辑。

## 更新与导出

保存修改后，已有纪要提示待更新。在纪要页点击「重新生成」，让纪要使用最新文字与显示名。

| 格式 | 内容 |
| :--- | :--- |
| Markdown | 会议纪要 |
| TXT | 带时间与说话人的转录 |
| JSON | 合并转录与录音元信息 |

导出取已保存内容。有未保存草稿时按提示先保存再导出。纪要失败不删除已完成的转录，修正配置后可重试。
